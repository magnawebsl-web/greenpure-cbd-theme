# GreenPure CBD Theme - Boréa CBD Edition 🌿

Ce thème WordPress est une version optimisée et enrichie pour **Boréa CBD**, conçue pour positionner la marque comme le leader européen du chanvre premium.

---

## 🚀 Pack d'Expansion "Leader Européen"

Ce dépôt contient désormais tout le nécessaire pour une installation "clé en main" :

### 1. **Catalogue de Produits (Data)**
- `/data/woocommerce_products_import.csv` : Fichier d'importation WooCommerce contenant plus de 20 nouvelles catégories de produits (Vapes, Gummies, Animaux, THCP, HHC-PO, etc.).
- `/data/products_for_import.json` : Données structurées pour des intégrations personnalisées.

### 2. **Visuels Premium (Assets)**
- `/assets/images/products-premium/` : Une bibliothèque complète de photos ultra-réalistes 8K avec le branding **"BORÉA CBD"** sur les étiquettes et packagings.
- Ces visuels remplacent les anciennes illustrations SVG pour une montée en gamme immédiate.

### 3. **Documentation Stratégique (Docs)**
- `/docs/Audit_Strategie_Borea_CBD.md` : Analyse comparative avec les leaders européens (Cibdol, Mama Kana).
- `/docs/Guide_Fonctionnalites_Leader.md` : Guide technique pour implémenter les modules de Transparence, Fidélité et Abonnements.
- `/docs/product_inventory.md` : Inventaire exhaustif des références et formats de produits.

---

## 🛠️ Guide d'Installation Rapide

1. **Téléchargement** : Téléchargez ce dépôt en format ZIP depuis GitHub.
2. **Installation WordPress** : Allez dans **Apparence > Thèmes > Ajouter > Téléverser** et sélectionnez le ZIP.
3. **Importation des Produits** :
   - Allez dans **WooCommerce > Produits > Importer**.
   - Sélectionnez le fichier `/data/woocommerce_products_import.csv` présent dans le thème.
   - Suivez les étapes pour peupler votre boutique instantanément.
4. **Configuration des Visuels** : Assignez les images du dossier `/assets/images/products-premium/` à vos nouveaux produits.
