## 🚀 Guide d'Implémentation Rapide

### Étape 1 : Importer les Produits dans WooCommerce
1. Allez dans **WooCommerce > Produits > Importer**.
2. Téléchargez le fichier `woocommerce_products_import.csv`.
3. Mappez les colonnes selon vos besoins.
4. Lancez l'importation.

### Étape 2 : Ajouter les Visuels aux Produits
1. Pour chaque produit importé, assignez les images correspondantes.
2. Utilisez les noms de fichiers comme guide (ex: `borea_huile_cbd_premium.png` pour les produits "Huiles").
3. Optimisez les images pour le web (WebP/Avif) via un plugin comme *Imagify*.

### Étape 3 : Mettre à Jour votre Thème GitHub
1. Clonez votre dépôt `greenpure-cbd-theme`.
2. Créez un dossier `/assets/images/products-expanded/` et y placez tous les visuels.
3. Créez un dossier `/data/` et y placez les fichiers JSON/CSV.
4. Mettez à jour le `README.md` du thème pour documenter les nouvelles catégories.
5. Committez et pushez : `git add . && git commit -m "feat: Add 20+ new product categories and premium visuals" && git push`.

### Étape 4 : Implémenter les Fonctionnalités "Leader"
Consultez `Guide_Fonctionnalites_Leader.md` pour :
- Module de Transparence (Lab Reports)
- Système de Filtrage par Effet
- Programme de Fidélité
- Abonnements Récurrents
- Optimisation SEO
